03 / Method

How I work.

I don't come from computer science. I build by directing AI: I write the brief, set the rules, test what comes back and keep only what works.

I

Brief

Say exactly what done looks like before anything gets built.

II

Rules

Hard limits the model must keep: what it never claims, never sends, never invents.

III

Test

Run it on my real week and check every output against the brief.

IV

Publish

Write it up plainly so anyone can use it, in any AI.
